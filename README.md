# MEN CRUD API

A simple CRUD API built using **Node.js, Express.js, MongoDB, and Mongoose**.

### Features

* Create data
* Read data
* Update data
* Delete data
* Search data
* Limit query results

### Technologies Used

* Node.js
* Express.js
* MongoDB
* Mongoose

### Installation

```bash
npm install mongoose express
```

### Run the Project

```bash
npm start
```

### API

```text
GET     /api/people
GET     /api/people/:id
POST    /api/people
PATCH   /api/people/:id
DELETE  /api/people/:id
GET     /api/people/query
```
